# App icons

These PNGs are copies of the services' website icons, retrieved on 2026-10-17.
Brand names and logos belong to their respective owners; inclusion indicates a shortcut, not a partnership.

- Icon Horse (`https://icon.horse/icon/<domain>`): Amazon, Gmail, Drive, Notion, Slack, GitHub, Outlook, Spotify, Dropbox, Trello, Netflix, PayPal, Canva, Figma, Proton.
- Google Calendar: `https://ssl.gstatic.com/calendar/images/dynamiclogo_2020q4/calendar_31_2x.png`
- Microsoft OneDrive: `https://res.cdn.office.net/files/fabric-cdn-prod_20221201.001/assets/brand-icons/product/svg/onedrive_48x1.svg`

Images are stored locally so these common services do not require an external request at display time.
For other public domains, the app requests only the hostname from Icon Horse, without the account URL, query string or referrer. If loading fails, a neutral app symbol is shown.
